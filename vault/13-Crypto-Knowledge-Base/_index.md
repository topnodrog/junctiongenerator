# Crypto Knowledge Base

Scraped, cleaned reference material on cryptocurrency — with an emphasis on
scams and security, in service of the anti-scam mission. Notes are generated by
the [`kb-crawler`](../../tools/kb-crawler/README.md) tool (crawl4ai → markdown)
and each preserves its `source:` URL for attribution.

> This is external reference material, distinct from the JGC project notes in the
> other vault sections. Treat it as a research library, not original writing.

## Categories

- **scams/** — fraud patterns, crime, attack techniques
- **security/** — wallets, key management, self-custody
- **fundamentals/** — foundational crypto concepts

## Adding to the base

Edit `tools/kb-crawler/sources.yaml`, then run the crawler (see its README).
Good candidates: scam-awareness guides, security best-practices, and — tying
into the site's affiliate partners — Ledger Academy / Kraken Learn articles
(vet each site's terms first).

## Ideas this feeds

- Source material for the weekly scam-defense blog posts (WEBSITE_GROWTH_PLAN.md)
- Eventual training/reference corpus for the planned on-site scam-check tool
