# 12-Tools

This section contains utility scripts and tools used in the JunctionGenerator project.

## Contents

- **validate_pptx.py** — Validates PowerPoint presentation file structure and integrity
- **verify_pptx_zip.py** — Verifies PPTX file integrity by checking internal ZIP structure

## Purpose
These Python utilities help ensure presentation files are correctly formatted and not corrupted. Useful when working with JGC_Funding_Pitch.pptx and other presentation materials.

## Usage
Run with Python 3: python script_name.py <file>
