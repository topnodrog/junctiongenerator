# JGC Financial Model & Projections

## Token Economics

### JGC Coin Supply
- **Total Supply:** Fixed (non-inflationary after genesis)
- **Precision:** 16 decimals
- **Divisibility:** Single-absorber dust mitigation (no sub-satoshi issues)
- **Distribution Model:** Genesis allocation → validator rewards → slashing deflationary pressure

### Revenue Streams (Year 1-3 Projections)

#### Validator Rewards
- **Mechanism:** Network security through stake + participation rewards
- **Revenue:** Transaction fees + inference-work rewards
- **Year 1 Estimate:** 100-200 validators earning 10-50 JGC/month = $50K-500K/month network security spend
- **Scaling:** 500+ validators by Year 2 → proportional security increase

#### Inference Marketplace
- **Use Case:** Enterprises verify computation outputs
- **Fee Structure:** 2-5% of inference work value
- **Year 1:** Conservative (testnet phase)
- **Year 2:** Early adopters in DeFi + insurance
- **Year 3:** Enterprise adoption → $1-5M annual protocol revenue

#### Exchange/Bridge Fees
- **Mechanism:** JGC ↔ other chains (JGT bridge, stablecoin pairs)
- **Fee Model:** 0.1-0.25% of bridge volume
- **Year 2:** Post-launch listing on DEXs → $100K-1M volume/month
- **Year 3:** CEX integration → $5-50M volume/month
