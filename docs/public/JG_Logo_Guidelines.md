# Junction Generator brand guidance

Updated 2026-09-05 UTC. Document owner: James Gordon.

Use **Junction Generator** for the project, **JGC** for the intended network,
and **JGTC** for valueless public-testnet coins. Keep the current stage clear in
external materials; a project logo does not imply a mainnet launch or partner
endorsement.

The live website uses a circular JG text mark, a dark green background, mint
accents, Outfit for display text, and JetBrains Mono for supporting technical
labels. Its implementation in `src/app/globals.css` and `src/app/layout.tsx`
is the source for website styling.

An earlier draft proposed emerald `#1FD9A6`, gold `#FFB84D`, and dark `#0D1117`
for presentation materials. Treat that as a historical palette, not proof
that a complete approved SVG/PNG asset collection exists.

Preserve proportions and readable spacing. Check the actual foreground and
background combination before using small text; the old draft's contrast
ratios were not verified and should not be reused. Do not invent asset download
links or claim that an unproduced logo variant is available.
